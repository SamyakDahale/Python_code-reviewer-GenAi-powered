# Python_code-reviewer-GenAi-powered
A **Python Code Review App** using **Streamlit** and **Google AI** that allows users to submit Python code for **bug detection, improvements, and fixed suggestions**. The app Provides an intuitive UI, analyzes code for errors, and returns AI-generated feedback with corrected snippets. 

Store the app.py in a folder and in the same folder create a textfile named **API_key** ;
in that text file, save the Gemini API key in plain format,

To run the program, type in ur IDE this - 
streamlit run app.py
